Ash Sample

An eight-voice sample-based synthesizer with 21.67 seconds of storage shared across eight sample slots.

Sample recording

Record USB audio in 16 kHz mono, up to 12 seconds per slot.

  • Select a slot.
  • Send audio over USB at source pitch C4.
  • Tap the leaf touch pad to start or stop recording.
  • Hold the leaf touch pad for one second to save.
  • LED colors: cyan = idle; red = recording; white = recorded, not yet saved; yellow = saving; magenta = save failed.

Connection

Connect to manage samples and settings on Ash. Use desktop Chrome or Edge, connect via USB, and allow MIDI access.

Sample Bank

Choose a slot and load a WAV file. The editor converts it to 24 kHz / 16-bit mono. Use SEND SLOT to save the sample and its playback mode on Ash.

  • LOOP repeats the sample while a note is held and during the release envelope.
  • ONE SHOT plays the entire sample once, even if the note is released early.
