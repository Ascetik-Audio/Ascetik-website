Ash Sample

Looping sample synthesizer and stereo USB audio interface.
8 slots · 8 voices · 21.67 seconds shared storage.
WAV imports: 24 kHz / 16-bit mono · source pitch C4.

USB Recording

Send computer audio over USB. Select a slot with Waveform.
Tap leaf: record / stop · Hold 1 second: save · Max 12 seconds.
16 kHz mono, lossy μ-law: lower quality than WAV imports.
Save before another take or power-off. Magenta = save failed.

Connection

Use desktop Chrome or Edge. Connect via MIDI and allow access when prompted.
