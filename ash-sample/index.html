Ash Sample

Sample-based 8-voice synthesizer with 21.67 seconds of storage shared by 8 sample slots.

Sample recording

Record up to 12 seconds per slot of 16 kHz mono from USB audio.

  • Select a slot
  • Send audio over USB (Source pitch C4)
  • Tap leaf: record / stop
  • Hold 1 second: save
  • LED colors: cyan = idle; red = recording; white = recorded, not yet saved; yellow = saving; magenta = save failed.

Connection

Use desktop Chrome or Edge. Connect via MIDI and allow access when prompted.

Sample Bank

Choose a slot and load a WAV file. The editor converts it to 24 kHz / 16-bit mono. Use SEND SLOT to save the sample and its playback mode on Ash.

  • LOOP repeats the sample while a note is held, then follows the release envelope.
  • ONE SHOT plays the sample once to the end, even if the note is released early.

Bank Backup

DOWNLOAD BACKUP saves all eight editor slots and their playback modes as one .ashs file on your computer. Use READ ALL first to back up the samples stored on Ash.

OPEN BACKUP loads an .ashs file into the editor, replacing its current slots. To restore it to Ash, select each slot and use SEND SLOT.
